# Regras específicas da repo

## Fecho de cada ronda

No fim de cada ronda que altere a app, reconstruir e abrir a versão mais recente para teste manual:

```bash
./scripts/run-prompt-wiz.sh
```

Só entregar a ronda depois de confirmar que o script concluiu o build e abriu a app. Comunicar explicitamente se essa execução falhar.
