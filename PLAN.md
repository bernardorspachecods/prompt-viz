# Plano de evolução

Este ficheiro só contém trabalho futuro explicitamente decidido. Não escolher uma próxima feature por inferência a partir do estado técnico.

## Próxima feature

Ainda não decidida.

## Como registar uma decisão

Quando a próxima feature for acordada, adicionar:

- objetivo observável;
- razão pela qual pertence ao produto;
- escopo incluído e excluído;
- critérios de conclusão;
- validação automática e manual necessária.
